# ARA 8.0 Frontend Live Coding Test

Selamat datang di tahap Live Coding Test untuk divisi Frontend ARA 8.0!
Repository ini adalah starter-kit yang akan kalian gunakan untuk mengerjakan soal tes.

---

## Instruksi Pengerjaan

Untuk sesi live coding kali ini, ikuti langkah-langkah berikut secara berurutan:

### 1. Fork Repository

- Klik tombol **Fork** di kanan atas halaman ini untuk membuat salinan repository ke akun GitHub kalian sendiri.

### 2. Clone ke Komputer Lokal

Buka terminal dan jalankan perintah berikut:

```bash
git clone https://github.com/[username-kalian]/ara8-frontend-live-coding.git
cd ara8-frontend-live-coding
```

### 3. Buat Branch Baru

Buat branch khusus untuk pengerjaan kalian:

```bash
git checkout -b [nama-kalian]-live-coding
```

### 4. Kerjakan Task

- Baca panduan dan lihat desain UI (Soal 1, 2, dan 3) yang harus dikerjakan pada link Figma berikut:
  **[Figma Live Coding ARA 8.0](https://www.figma.com/design/GL12yagvAqC2CP62bAggIr/Live-Coding-ARA-8.0?node-id=1-6&p=f&t=H38aKXcE3a8yQ0Bx-0)**
- Lakukan **commit secara berkala** dengan pesan commit yang jelas. _(Jangan hanya membuat 1 commit besar di akhir — kami ingin melihat proses dan alur kerja kalian)._

### 5. Push & Submit

Setelah selesai mengerjakan soal, lakukan push ke repository kalian:

```bash
git add .
git commit -m "pesan commit"
git push origin [nama-kalian]-live-coding
```

- Buka repository hasil fork kalian di GitHub, lalu buat **Pull Request (PR)** ke repository asli ini ke branch `main`.
- Beri judul PR: `[Nama] - [Divisi] - Live Coding Test`
- Di deskripsi PR, jelaskan secara singkat pendekatan/solusi yang kalian gunakan.

### 6. Deadline

Submit PR paling lambat **[8 September 2026, Pukul 18.30]**. PR yang masuk setelah waktu tersebut tidak akan dinilai.

---

## Catatan Penting

- Pastikan repository hasil fork kalian bersifat **Publik**.
- **Aturan AI:** Kalian **diperbolehkan** menggunakan AI asisten (seperti ChatGPT, Copilot, Cursor). Namun, dilarang keras menggunakan fitur _screenshot-to-code_ (memberikan gambar desain ke AI untuk digenerate otomatis tanpa kalian memikirkan logikanya). Kalian juga **wajib bisa menjelaskan** fungsi dari setiap baris kode yang kalian tulis atau _copy_ saat sesi review/interview nanti.
- Jika ada kendala teknis atau pertanyaan, silakan bertanya ke panitia yang bertugas.

Selamat mengerjakan dan _Good Luck_! 🔥
